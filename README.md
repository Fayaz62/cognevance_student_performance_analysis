## 📌 Project Overview

The **Student Performance Analysis** project focuses on analyzing academic performance using Python and data analytics techniques. The project explores how factors such as attendance, study hours, and motivation level influence students' exam scores.

The objective is to clean the dataset, perform exploratory data analysis (EDA), visualize important trends, and generate meaningful insights that can help improve student performance.

---

## 🎯 Objectives

* Collect and analyze student academic performance data.
* Clean and preprocess the dataset.
* Study attendance and exam score relationships.
* Visualize performance trends using charts.
* Generate insights and recommendations based on data analysis.

```bash

```

4. Run all cells to reproduce the analysis and charts.
